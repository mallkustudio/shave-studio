# Shave Studio Booking System

## Objetivo
Construir un sistema de reservas moderno para Shave Studio, separado de WordPress pero integrado visual y funcionalmente con la web principal.

## Contexto
La web pública y visual se está construyendo en WordPress.
El sistema de reservas se desarrollará aparte y luego se integrará a la web.

## Usuarios principales
1. Cliente
2. Barbero
3. Administrador / dueño

## Necesidades del cliente
- Ver barberos disponibles
- Entrar al perfil de un barbero y reservar con él
- Ver horarios disponibles y no disponibles
- Reservar desde celular o desktop
- Recibir confirmación de la reserva

## Necesidades del barbero
- Tener un perfil propio
- Ver su agenda
- Gestionar reservas
- Cancelar o editar reservas
- Crear reservas manuales recibidas por WhatsApp o fuera del sistema

## Necesidades del administrador
- Ver todas las reservas
- Gestionar barberos
- Gestionar horarios
- Gestionar servicios
- Poder crear, editar y cancelar reservas

## Requisitos funcionales iniciales
- Frontend público de reservas
- Panel de gestión para admin y/o barberos
- Disponibilidad por barbero
- Asociación de reservas a un barbero
- Visualización de horarios disponibles
- Creación manual de reservas
- Cancelación y edición de reservas
- Diseño visual compatible con la web de WordPress

## Requisitos no funcionales
- Mobile first
- UI estética y premium
- Estructura mantenible
- Preparado para futura integración con WordPress
- Preparado para crecer a nuevas funciones en el futuro

## Alcance MVP inicial
- Reservar con barbero
- Ver disponibilidad
- Crear reserva
- Editar/cancelar reserva
- Crear reserva manual desde panel
- Gestión básica de agenda
